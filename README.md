# Quora-like Posts Application

A simple web application inspired by Quora that allows users to create, view, edit, delete, and like posts.

## Features

- Create and publish new posts
- View all posts in one place
- View individual post details
- Edit and update existing posts
- Delete posts when needed
- Search posts by relevant Username
- Like posts with a single click

## Tech Stack

- Node.js
- Express.js
- EJS
- JavaScript
- HTML & CSS

## Project Highlights

- Implemented RESTful-style routes for post operations
- Used Express.js for backend routing
- Used EJS for server-side rendering
- Managed post-related operations through backend routes
